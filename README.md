# AAHARITHM 🥗🩺

> An intelligent, zero-dependency Patient Management System (PMS) and Diet Coach prototype built with vanilla HTML, CSS, and modern JavaScript.

---

## 🌟 Overview

**AAHARITHM** is a frontend-first clinical management and dietary advisory platform. It empowers healthcare providers and dietitians to manage comprehensive 360° patient records and generate personalized, condition-aware dietary guidelines directly in the browser.

All data persists in the client's `localStorage` — requiring zero backend servers, zero installations, and zero external build tools.

---

## ✨ Features

- **🏠 Interactive Dashboard**: Real-time KPIs (total patients, active diets, upcoming appointments, critical alerts) and quick patient management.
- **👥 Patient Directory**: Search, filter, and inspect patients with immediate access to records.
- **🩺 360° Comprehensive Health Profile**:
  - Demographics, BMI, and vital statistics
  - Conditions & Diagnoses
  - Allergies & Sensitivities
  - Medication Tracking
  - Lab Results & History
  - Immunization Records
  - Lifestyle & Fitness Metrics
  - Appointments & Consultations
  - Clinical Notes & Care Team
- **🥗 Intelligent Diet Coach**:
  - Interactive dietary consultant
  - Formulates meal recommendations tailored to patient conditions, allergies, and lifestyle targets
  - Supports rule-based clinical nutrition guidance
- **🎨 Modern Responsive Dark UI**: Optimized for desktop, tablet, and mobile browsers with native CSS glassmorphic design.
- **💾 Local Storage Persistence**: Changes are automatically saved to browser storage with import/export and reset options.

## 🚀 Getting Started

No installation, Node.js, or compilation steps required!

### Option 1: Open Directly in Browser
Simply open `index.html` in any modern web browser:
```bash
git clone https://github.com/snowysaumya10/AAHARITHM.git
cd AAHARITHM
open index.html # On macOS (or double-click index.html)
```

### Option 2: Run with a Local Server (Optional)
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Custom dark-mode UI with CSS variables and responsive grid/flexbox layouts.
- **Vanilla JavaScript (ES6+)**: Zero external libraries or runtime dependencies.
- **Storage**: Browser `localStorage` API.
